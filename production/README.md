# Production

How the studio coordinates. Agents read the relevant files before a task and update them after.

| File | Purpose | Who edits |
|---|---|---|
| [TASKS.md](TASKS.md) | Task board: ID, owner, status, dependencies, acceptance | Director |
| [CONTRACTS.md](CONTRACTS.md) | Shared formats, folder ownership, naming, scale, host/client split | Director (changes need a DECISIONS entry) |
| [DECISIONS.md](DECISIONS.md) | Every decision that affects another role | Director |
| [QUESTIONS.md](QUESTIONS.md) | Blocked? Ask here, addressed to a role. **FOR CEO** items wait for the next STOP | Anyone appends; Director answers |
| [OPEN_ISSUES.md](OPEN_ISSUES.md) | Problems from playtests and reviews, for the between-phase review | QA and Director |
| [handoffs/](handoffs/README.md) | One note per finished task | Task owner, then QA |
