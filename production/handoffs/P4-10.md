## Done

- **Dawn save** (`game/core/save.gd`, `class_name Save`): `Save.build` / `write` at dawn step 6 (`Death.step_save`). Saved: day, difficulty, headcount, coins, final_extra, free scrap, plots, store (team items, own by uid, scrap, flares, crows, bought plots), `Game.roles` (by uid), uids, Prize Pumpkin fields, debt (pcts, paid, penalty, foreclosed, lost, first_due, first_made), generator damage, creature body (P4-13, forced on load: log `creature_body forced:"save"`), walkie batteries by uid, `Game` flags in `Save.GAME_FLAGS`, and `extras` from any node in group `saveable`.

- **Load**: main menu "Load Season" list; `--load=<id|path>`; `Save.apply_pending` at the end of `Main._ready`. Wrong uid: "You were not in that season.". Roles lock once the season has uids.
- **Host left**: `Net.host_left(how)` (`quit` via `apply_host_leaving`, else `timeout`), pause menu card "The host left. / The season continues from the last dawn save. / Any farmhand from this season can host it."; Quit -> `Game.quit`.
- **Joining and leaving**: `Debt._headcount_changed()` re-scales owed and re-sends on join/leave (log `debt_rescaled`, seen in run B: players 1, owed 767, pct 59). `WaitingCard` stops the clock at a dawn with a 2+ roster but fewer than 2 humans.
- **Q-089**: `Data.scaled()` clamps debt/bill players to 2..max; solo bill reads 59%.
- **Walkie (P4-14)**: batteries saved by uid and remapped on join (`Save._remap_walkie`). Written against the walkie API as described in the Director's message; not run against the real `walkie.gd` (9ff9f3d is not in this worktree).
- **Awards tally (P4-15)**: `Save.tally_state/tally_load`, `Save.tally_left` (absent farmhands' counts kept and re-saved). `_hm_wipe` is a bool, saved with it. SeasonAwards itself not edited (10c609a not in this worktree): exact code in Q-123.
