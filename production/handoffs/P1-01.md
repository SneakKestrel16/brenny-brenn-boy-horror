## What the next role needs to know
- **Schemas for the Director to approve** (CONTRACTS section 6 says A.x are final but the file list
  has no Phase 1 timers):
  1. `season`, `labor` unchanged from doc 02 A.2, A.3 (extracted by script from the doc).
  2. `crops.schema.json` differs from A.4 only in `allOf`: it requires `turnip` alone, because
     `pumpkin` and `moonflower` arrive in Phase 2. Restore the other two then.
  3. `creature`, `voice_lines` have no schema in doc 03; proposed here. `creature` is `kind`-tagged:
     `body` (`signature_sound`, `quirk` null), `speed` (`speed_mps`), `timer` (`seconds`), `distance`
     (`metres`), `mult` (`mult`), `noise` (`radius_m`; `noise_voice` adds `exponent`, `byte_max`
     for `radius = 60 * (byte/255)^2`). `voice_lines` is `line`/`stranger` (`text`,
     `staged_moment`, `phase1`) or `sound_lure` (`sound_id`, `phase1`). The `name:<player_uid>`
     line is generated at runtime from player names, so it is not a record (id pattern forbids `:`).
  4. **New file `phase1.json`** (not in CONTRACTS' 18): scripted DD Phase 1 timers, one record per
     value with a typed field (`seconds`, `metres`, `count`, `percent`, `flag`, `seconds_list`,
     `ids`). Needs a CONTRACTS section 6 line and a DECISIONS entry if approved; `Data` should
     load it only when `--phase1` is set. Alternative: fold it into `creature.json`.
- `season.json` units: the A.2 schema's `unit` enum has no type for strings and booleans, so
  `foreclosure_penalty_rounding`, `foreclosure_seizure_order` and `free_scrap_stacks` use `count`
  as a dummy. Suggest adding `none` to the enum.
- Retreat time differs by design: `creature.retreat_s` 30 s (doc 03 4.1) against
  `phase1.scripted_retreat_s` 10 s (doc 03 18). Phase 1 scripts use the second.
- `voice_lines` stranger lines are text only; audio is synthetic and made outside the repo.
