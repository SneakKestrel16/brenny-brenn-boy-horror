- `animal_crow`: nodes `Armature` (Skeleton3D, bones `body`, `head`, `tail`, `wing_l`, `wing_r`), skinned meshes `Body`, `Head`, `Tail`, `WingL`, `WingR`. AnimationPlayer: `idle` (2 s), `caw` (1 s one-shot), `fly` (0.5 s, 2 flaps per second, under the D-046 limit of 3 per second). Loop imports as none: set `LOOP_LINEAR` on `idle` and `fly`.
- `prop_dead_crow`: single node `DeadCrow`, static.
- `tool_hands`: nodes `HandL`, `HandR`, pivots at the elbows (-0.19 / +0.19, 0, 0); the arms reach local +Y (Godot -Z in the model after export, check in the scene). Material `mat_farmer_sleeves` only (the Taint slot). Shader distance for `TaintLook` = local +Y from the elbow (arm length 0.42 = `ARM_LEN`; model arm 0.53 including the hand).
- `prop_road_sign`: node `Sign`, static. Painted lettering is stand-in bars only.
- `prop_road_lamp`: nodes `Lamp` and an empty `LightRig` at (0, 0, 3.26) for the game to hang its light on. The glass is its own surface in `mat_emissive_warm` (dim it with a surface override).
- `char_farmer_ragdoll`: same mesh, 12 bones (`hips`, `spine`, `arm_l`, `forearm_l`, `arm_r`, `forearm_r`, `head`, `hat`, `thigh_l`, `shin_l`, `thigh_r`, `shin_r`) and materials as `char_farmer` (`mat_farmer_overalls` is the player tint, `mat_farmer_sleeves` Taint, `mat_flat_lit`). Build PhysicalBoneSimulator3D in code from the Skeleton3D. One pose animation `lie` (on its back) for use without physics (Q-322).
- `char_ghost`: same 12 bones and part nodes as the farmer, animations `idle` and `float` (3 s slow drift; set loop in code). One material `mat_ghost_shell`: glTF alphaMode BLEND, alpha 0.42, cold blue-white tones, darker eyes and mouth, no emission. Alpha is static, so the model never flashes (doc 01 "Photosensitivity safety"). Game side: `cast_shadow = OFF`, fade the alpha with light level, optional rim; any pulse stays under 3 per second.
