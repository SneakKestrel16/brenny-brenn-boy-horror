## What was done

- **Push bar shows the route** (OPEN_ISSUES item 13). `cart.hold_progress(&"push_cart")` returns
  `[offset / length, "N m to the gate"]` (`ceili(length - offset)`), from the synced cart, so every peer
  reads the same value. `HoldController.hold_state()` now returns `[verb, progress, note]` and uses a
  target's `hold_progress` when it has one (otherwise the old timer and `""`); the hold ring scale uses
  the same progress. `hud.gd` is a one-line change: the prompt appends the note, e.g.
  "Push Cart... 3%  143 m to the gate". Push behaviour and cart speeds (doc 02 s9) unchanged.
- **Push from the handle.** `cart.gd` adds a `Handle` Node3D at the model's push bar: local
  `(0, model y + 1.05, +1.45)` (source `tools/blender/build_phase4.py` `cart()`: handle bar x -0.55..0.55
  at Blender y -1.45, z 1.05; Blender -Y is the cart's +Z here). `verbs_for` offers `push_cart` only when
  the local player stands within 1.5 m (flat) of the handle. `load_cart` unchanged. The host's
  `can_start` is not handle-gated, so bots that ask from `target_pos()` still push; the lock snaps them
  to the handle. **3D Artist does not need to add a handle**: the model already has a clear push bar.
- **Lock to the cart while pushing.** `cart.push_slot(peer)`: slot 0.4 m behind the handle, pushers
  side by side 0.7 m apart in `pushers` order; `Vector3.INF` unless the peer is in `pushers`, act is
  push or gate run and `stall_s <= 0`. So release, knock-off (stall), death (dropped from pushers) and
  cart out all free the player. Host: `players.submit` pins the frame's xz to the slot and skips the
  speed check for that frame. Client: `player.gd` walks its body to the slot each frame, faces the
  route at lock start, then adds the cart's heading change each frame so it turns with the route (mouse
  look stays free on top), WASD ignored while locked.
- **QA flag** `-- --autopush`: walk to the handle on the Harvest Moon, push 12 s, log `autopush_step`
  each second (slot distance, `hold_state`), release, log `locked`.
- **Doc 05 s13** updated (handle, lock, bar, QA flag).
