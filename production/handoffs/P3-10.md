## Done

  (the crow perch while the ghost is in a crow). Ghosts hear each other, and the living, clean. Playtest
  issue 9's mute in `player.gd` is gone.
- `Voice.hears_static(speaker)`: the one test for real voices and clip lures (speaker dead, listener alive).
  `creature.gd` `_hear_lure` uses it, so a dead owner's fake plays through the same static. Static alone cannot
  tell real from fake; only the flicker can (doc 01 "The tiebreaker").

  `VoiceGhostEcho`, `VoiceGhostPitchUp` and `VoiceGhostPitchDown`, which send into it. `bus_for(tell, ghost)`
  picks one. `attach_static` adds the `GhostStatic` layer at -12 dB: one second of generated noise from a fixed
  seed, with no recorded file. `attach_crackle` adds it on any ghost bus, even with the `no_crackle` tell.
- Every live `VoiceEmitter` now carries the `Crackle` layer, so the crackle on a fake is no longer a tell.
  Both layers play only during a talk spurt (`VoiceEmitter.talking()`).
- `Voice._apply_buses` (it replaces `_apply_capture_mute`) sets each emitter's bus and layers every frame:
  `VoiceMuted` while capturing, else the ghost or base chain.
- Ghost frames still never feed the creature (D-011, unchanged). The host logs each ghost talk start as
  `ghost_action` with `kind` `static_voice`, and `check_logs.py` tallies it.
- `voice_stats` gains `bus` and `static`.
- `game/voice/check_voice_chain.gd`: checks the bus map, the sends, the static stream, and the layers on
  ghost and living fakes.
