# P5-05 Cosmetics (Gameplay Programmer)

## What was done

- Autoload `Cosmetics` (`game/items/cosmetics.gd`): host-authoritative buy and wear of the 6 hats and 5 overalls in
  `data/cosmetics.json`. Sold only once the debt is paid (`Debt`: not lost, paid > 0, owed == 0); paid from team coins at
  the crate (range check `store._too_far`), or anywhere once `Clock.season_over` (the Season's End card covers the world,
  the crate is out of reach). Owned by uid, no gameplay effect, saved in extras key `cosmetics`, restored in `Game.load_season`.
- Every peer sees every look: host broadcasts `apply_cosmetics`; `CosmeticDress` (child of each non-local Player) adds the hat
  and the overalls tint. Lobby line-up shows the worn hat in place of the role hat (D-144, doc 07 s8, Q-255 item 3).
- UI: `CosmeticsPanel` in pause menu (lobby and match: wear), store menu and Season's End card (buy and wear).
- Doc 05 section 20.1 added. `cosmetics` is in `Data.TABLES` (Q-255 item 4).

## Notes for others

- P5-04: ownership lives in the `Cosmetics` autoload (process-wide, uid keyed) and save extras `cosmetics`; it is not reset
  by a new season. Coins are deducted at buy, so compute savings after cosmetic spending.
- P5-06: file names `char_hat_<id>.glb` (origin at band bottom) and `char_overalls_<name>.glb` where name = id minus
  `overalls_`. Falls back to a primitive when absent. The glTF extra `tint` format (`#rrggbb` string or [r,g,b]) is
  inference; the overlay re-parenting (`attach_overlay`) is untested: world bodies are capsules with no Skeleton3D yet. The
  overalls tint is applied as `material_override` on the body mesh and restores whatever P5-13 set when removed.
- Doc 07 s8 owner: add that a worn cosmetic hat replaces the role hat on the model (role stays on the role card).
- Placeholder looks and colours (`HAT_LOOK`, `TINT_LOOK`) are mine, not from doc 07.
- Gotcha: a Player's `peer` is set after `_ready`, so `CosmeticDress` refreshes on peer change in `_process`.
  A hat added by name reads `@Node3D@N` on a client for unknown reason; tests use `CosmeticDress._hat`.
