Owner: AI Programmer. Sources: doc 01 "The Creature > Bodies", doc 03 s2, doc 08 s6, D-068, Q-074.

## What was done

- The host picks one of the four bodies once, in `Creature._ready` (`_pick_body`), from the
  `creature.json` records with `kind` `body`. The seed is `--seed=<n>`; without it the seed is
  `hash(session_id)`, so unseeded seasons differ. Inference: doc 01 names no seed source. Settle: the
  P4-10 save stores the pick.
- `--body=<id>` forces the body (`boar` and `body_boar` both work). An unknown id logs a warning and
  falls back to the seed.
- The body reaches clients in every `apply_creature_state` (already in the packet). A client used to
  apply the body only on a state change, so a lurk-time pick never arrived. Now the first packet
  (the `farm_state` reply on load or late join) sets it and re-emits `state_changed`, and
  Soundscape picks the matching `cre_<body>_sig_chase`.
- Log: `creature_body` once per season on every peer. Host `{body, seed, forced}`, client `{body}`.
- Bodies differ by sound only (doc 08 s6): the placeholder capsule is the same for all four until
  P4-16.
