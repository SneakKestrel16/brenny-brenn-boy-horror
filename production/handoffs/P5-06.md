## How to use
- Hats: `BoneAttachment3D` with `bone_name = "hat"` on the farmer Skeleton3D, hat glb as child. Origin is the band bottom centre, same as the role hats. Vertex colour, nothing emissive. Import files use `vcol_post_import.gd` (needed for vertex colours; kept set).
- Overalls (doc 07 s8, "tint or mesh": both): each glb is a skinned decoration overlay weighted to the same 12 bones as `char_farmer`, with nodes `Torso`, `LegL`, `LegR` under `Armature`. Re-parent those MeshInstance3D nodes into the farmer's Skeleton3D and set `skeleton = NodePath("..")` (as `tools/blender/cosmetic_shots.gd` does). It follows every animation; no animations in the overlay glb.
- Tint source of truth: Armature custom props in the glb (glTF extras, Godot metadata `extras` on the node carrying it): `tint` and `cosmetic_id`. `denim` `#3F5F8F`, `gold` `#D9AE2C`, `patched` / `striped` / `plaid` = `"player"` (keep the player colour on `mat_farmer_overalls.albedo_color`, set it per surface override). Doc 02 s21.5 / `overalls_use_tint_slot: true`.
- Accent colours are neutral (ink, cream, brown, brass) so they read on all six player colours (D-159). Screenshots use red `#C04040`.
