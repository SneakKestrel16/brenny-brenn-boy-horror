## Done

- **Smoke run.** `uv run tools/qa/smoke.py` runs three steps: the headless import (the CONTRACTS
  section 1 command), a parse check of every `.gd` under `res://`, and a timed headless run
  (`--quit-after 120` by default, change with `--frames`).
  - A step fails on any `ERROR:` / `SCRIPT ERROR:` / `USER ERROR:` / `SHADER ERROR:` line, a crash
    banner, a non-zero exit code or a timeout. The ANSI colour codes Godot prints are stripped first.
  - `--clean-import` deletes `.godot/` first.
- **Multi-instance launcher.** `uv run tools/qa/multi.py -n 2..4` starts the instances.
  - Arguments: `--args` gives one instance its own (repeated, in instance order); `--common` goes to
    every instance. Engine flags and the game flags after `--` are merged.
  - Windows are tiled in a 2x2 grid, or use `--headless`. `--frames`, `--duration` and `--stagger`
    control how the run starts and ends.
  - Collected into `logs/qa/multi_<timestamp>/`: each instance's console log, every section 10
    `.jsonl` created or grown during the run (copied from the real `user://logs`), and
    `manifest.json`.
  - The script asks Godot for the real `user://` path each run. Here it is
    `C:\Users\Ockey\AppData\Roaming\Godot\app_userdata\Brenny Brenn Boy Horror`.
- **Log checker.** `uv run tools/qa/check_logs.py <paths>` reads the section 10 JSONL and reports
  three doc 01 measures:
  - **Lure success rate:** doc 01 "Testing" rule, recomputed rather than trusted, and checked against
    the Phase 1 gate of at least 30% (doc 01 Build Plan).
  - **Trap race results:** overall, and for the doc 01 "solo, untainted, pried at once" case.
  - **Spatial audio trials:** results by sound and distance, plus the 10, 30 and 60 m cells not
    tested yet.

  It also tallies deaths, sprung traps, money changes, hold times by verb and time inside at night.
  Measures come from the host file (peer 1) only. The checker validates the record shape and phase
  IDs. When no events are logged it prints "none logged". `--json` and `--strict` are available.
- **Self-test.** `uv run tests/qa/test_harness.py` runs 14 tests on fixtures, covering the checker,
  the error scanner and the launcher's argument building. Godot is not needed.
- **Docs.** All of this is documented in `tools/qa/README.md`.

## What the next role needs to know

- **Before handing off any task**, run `uv run tools/qa/smoke.py`. QA runs the same command when it
  reviews.
- **Networked features** are checked with `uv run tools/qa/multi.py -n 2 ...`, then
  `uv run tools/qa/check_logs.py logs/qa/multi_<ts>/user_logs`.
- **The game's log writer (`Log` autoload, Gameplay Programmer):**
  - write `user://logs/<session_id>/peer_<id>.jsonl`, exactly as CONTRACTS section 10 says;
  - flush each line, because a killed instance otherwise loses its tail;
  - all local instances share one `user://`, so give each peer its own file name.
- **Game command-line flags** (host, join, bot) should be read from `OS.get_cmdline_user_args()`.
  The launcher passes everything after `--` there.
- **The parse check loads every `.gd`**, including `spikes/`. Put a `.gdignore` in any folder that
  must be skipped.
- **Gotcha:** the root `.gitignore` ignores any folder named `logs/` at any depth. Test fixtures
  must not live under a `logs/` folder.
