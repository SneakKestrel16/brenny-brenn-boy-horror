# P5-66: Ghost-possessed crow flies
Owner: Gameplay Programmer  Date: 2026-10-10

## Design
Doc 01 "Ghosts" says only "possess one crow per night for 20 seconds, to scout and point"; all flight numbers are
placeholders (inference). Kept: 20 s, one a night, 20 m reach, one ghost per perch, ghost-only, no Noise, no harm.
- Client ghost sends `request_crow_steer(dir)` (new, unreliable ordered, 20 Hz): world direction = move keys x camera basis,
  so forward, turn, climb and dive follow the look direction. No new input action.
- Host moves the crow (`GhostPowers.fly`, static): 7 m/s, y clamped 1 to 8 m (boundary walls are 10 m), a ray on layer 1
  stops it before buildings, roofs and walls (radius 0.4 m). Steer older than 0.4 s = hover. Host re-clamps `dir` to length 1.
- Host broadcasts `apply_crow_pos(peer, pos, yaw)` (new, unreliable ordered, 20 Hz) to all. `apply_crow_possessed(peer, id)`
  now goes to every peer (was the ghost only); `""` = let go.
- Every peer draws one `animal_crow` (clip `fly`, smoothed), perch crow hidden. Ghost camera rides the crow. Caw sounds at the crow.
- End: the crow flies back to its perch (8 m/s, local on every peer, nothing synced), lands, perch crow shows again.
- Corner cut: a client that joins mid-flight does not see that crow (20 s; no state sync).
- Controls unchanged: Lantern key takes a crow, use_tool caws, move + look flies. HUD ghost line now says "steer it".

## QA review
**Verdict: PASS** (QA, 2026-10-10), with one Director action: Q-357 (DECISIONS entry for the two new RPCs, CONTRACTS s7).

Checked:
- **Real play, no bypass.** New `tests/qa/qa_p5_66_crow_client.gd` runs as the client of a windowed 2-instance session
  (ports 35066-35070). Intro card holds `Game.console_open`; one key event clears it (no bug: the builder's runs never

  mid-flight: `respawn`, then `back:true` within 0.3 s and lands. No ERROR lines on any instance.
- **Host authority.** Steer is stored only when the sender holds a crow (`_crows.has(sender)`), clamped to length 1, stale
  after 0.4 s (hover). Host is the only mover. Both streams 20 Hz (`CROW_SEND_S`). Screenshots: builder's client view and
  QA's `qa_host_view.png` / `qa_client_view.png` show the same flying crow (wings spread, same spot) on both peers.
- Other ghost-touching tests PASS: test_horror, test_dawn_cashin, test_prize_pumpkin, test_quirks, test_walkie,
  test_dawn_report_logic, test_p4_34, test_p5_33_night; check_ghost PASS. Import 0 ERROR, parse_check failed=0,
