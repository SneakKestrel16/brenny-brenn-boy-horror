# P1-04: Player controller, move stream, host speed check, Noise
Owner: Gameplay  Date: 2026-10-07

## Done
- `game/player/player.gd`: `CharacterBody3D` built in code (capsule 1.8 m, eye 1.65 m, CONTRACTS s3). Local: mouse look (Settings sensitivity, fov), WASD, crouch (hold or toggle setting), sprint with stamina (`max_s` 6 / `refill_s` 10 from `labor.json`, doc 02 2.2), go_still freezes input, collides with layers 1 and 5 (corn blocks players). Remote proxy: no input, exponential smoothing toward the latest target.
- `game/player/players.gd` (`Players` node, created by `main.gd`): spawns one Player per peer at `player_spawns` (by roster order), 20 Hz `move` client -> host, 20 Hz `moves` host -> all, host speed check, footstep Noise.
- `game/player/move_frame.gd`: wire format (type byte, seq u32, pos, yaw, pitch, flags; 25 B per frame). `game/player/speed_check.gd`: pure check, max x1.2 clamp, over 3x is a teleport (doc 06 s6).
- Host speed check: dt = max(host receive time, seq delta / 20 Hz) so bunched packets are not spikes; max from the frame's crouch/sprint flag times `Game.players[peer].speed_mult` (hook for Taint/Shaken/trap slow, default 1). Violation logs `speed_violation`; teleport sends `apply_teleport` (Net RPC) to the sender.
- `game/core/noise.gd` autoload `Noise` (after `Game` in `project.godot`): `emit`, `emit_kind` (radius from `creature.json` `noise_<kind>`, x1.5 Tainted steps, placeholder const), `emit_voice`, `noise_emitted`, per-kind `counts`. Rejects ghost sources; radius <= 0 only counts.
- Footsteps: host emits one `step_*` per 1.6 m (`STRIDE_M`, placeholder) from the `move` stream. `step_sprint_corn` uses a layer-5 point query; it never fires in the gray box because corn blocks bodies.
- `game/net/net.gd` (Network & Voice's file, minimal additions): `send_bytes(peer, packet, channel = 1)`, signal `bytes_received`, RPC `apply_teleport` + signal `teleport_received`. `to_host` not added (nothing needs it yet; `Net.to_peers` unchanged).
- QA flags (user args after `--`): `--autowalk` (local player walks a circle, alternates sprint), `--log-noise` (host logs `noise_emitted`), `--log-moves` (each machine logs where it sees every player once a second, event `player_positions`).
