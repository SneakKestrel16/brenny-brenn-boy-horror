## What was done

- **Store menu.** Press `interact` (E) at the shipping crate with nothing aimed and nothing held: a menu
  opens. It lists every `store.json` item with its price and a Buy button, then one seed row per crop in
  crops.json (doc 02 s10 prices). Buy sends the existing `request_store` (`buy`, id). The host validates it
  as before; a refusal shows under the list ("Not enough coins"). Rows grey out when they cannot be bought
  (locked day, owned, max bought, no coins). E or Escape closes the menu. Game keys are off while it is open
  (`Game.console_open`, as the pause menu does).
- **Seeds (CEO change, D-093, supersedes D-090; answers Q-170).** Seed rows have `Buy 1` and `Buy 5`. They send
  `request_store` op `seeds`, arg `<crop>:<n>` (net.gd's RPC has one arg; n 1 to 10). The host checks reach,
  ghost, unlock and coins (`Store.seed_why_not`), charges crops.json `seed` x n (ledger reason `seed`), and adds
  to the team stock `store.team["seed_<crop>"]`. That dictionary is saved and replicated already. Planting an empty
  plot uses one seed of its crop and charges nothing (`plot.gd`; refusal `no_seeds`). Aiming at an empty plot with
  no seed of its crop, the prompt says "Buy seeds at the store". Each row shows "have N", or why it is locked
  ("from dawn 4, if the first payment was made"); the moonflower row adds "(moonflower bed)".
  T (`cycle_seed`) cycles only among owned day crops; `Farm.planting_seed()` falls back to the first owned.
- **Bots** (`game/bots/bot.gd`, AI Programmer's path, minimal edit): `_plantable()` buys one seed of the plot's
  crop from anywhere (as `_scrap_ok` buys scrap) just before planting, so bots keep planting and keep the
  simulator's cash timing. The QA `--autochore` host buys the two seeds its script plants.
- **Hotbar.** Bottom-centre slots for what the local player holds (watering or fuel can, Prize Pumpkin,
  shovel, bear trap, crop bag, the team's seeds with counts, only once any are owned) and what the team owns (flare gun, scarecrows to place, quiet
  can, walkie and batteries, brighter lantern, scrap). Each slot has a one-line use hint with the bound key.
  Hidden for ghosts. D-091 records it as a CEO-requested exception to doc 05 s16 "No HUD markers".
- **Crate prompt** now reads "E: open the store (seeds and tools)".
- `Store.why_not(peer, id, near=false)` no longer calls the host-only `farm.pstate`, so clients can call it.
- QA review fixes. `Store.prompt_text(at)` now takes the local body's position. The old code read
  `Game.players[me].pos`, which only the host sets, so on a client the menu never opened. The locked pumpkin
  row says "from dawn 4, if the first payment was made" (doc 02 s10). A seed pick that is no longer on sale
  falls back to the default seed (hud.gd `_slots`). The crate prompt hides while the menu is open, and the
  controls hint sits higher so the prompt does not overlap it.
