## What was done
- **Farmer** (`game/player/farmer_body.gd`, new): instances `char_farmer.glb`, loops idle, walk, run, crouch (LOOP_LINEAR), tints surface `mat_farmer_overalls` with the player colour through a per-instance surface override (the glb materials are shared). API: `loop(anim, speed)`, `shot(anim)`, `has_anim`, `colour(slot)`.
- **Player** (`game/player/player.gd`): the capsule mesh is the farmer. `_animate` picks the animation from the horizontal speed of the position delta (crouch, run above 1.3 x walk speed, walk above 0.3, else idle; above 20 m/s is a teleport and ignored). Because it reads positions, remote players animate the same way as the local one with no extra sync. Emotes wave, point, shrug, scream play the matching glb animation (`play_emote` -> `_mesh.shot`). The old arm/tween emote and the crouch squash are gone. New `set_colour_slot(slot)` re-tints a live body.
- **Colours, host-sent (D-159, D-165, Q-282):** `Game.colours` (host: player uid, or "peer<id>" without identity, to slot; season-long) and `Game.colour_slots` (peer to slot; the client mirror). `Game.assign_colours()` runs on the host: pass 1 keeps a stored slot when it is free, pass 2 gives each new player the lowest free slot. `Game.colour_of(peer)` assigns on demand on the host and returns -1 on a client until the table arrives. `Roles.sync()` adds `table["colours"]` to the existing `apply_roles` table (already sent on join, rejoin and role change), and `Roles.apply()` stores it on a client. `Players._on_roles` (on `Game.roles_changed`) re-tints and logs `player_colour` (peer, slot, hex) from the received value, once per change. Peers never derive a slot. `net.gd` is unchanged.
- **Lobby** (`game/ui/lobby.gd`): `LineUp._farmer` uses `FarmerBody`; the slot comes from `Game.colour_of`, with the sorted rank as a fallback.
- **Creature** (`game/creature/creature.gd`): the glb `creature_<id>` is child "Art" (via `CreatureLook.apply`), swapped when `body` changes; the capsule collider stays (Q-150). `ghost_view` is toggled for ghosts. `dev_toys._creature_parts()` finds "Art" and no collider (tested). Bug found and fixed: `body_husk` looked for `creature_husk.glb`, but the file is `creature_corn_husk.glb`; `_show_body` maps id "husk" to "corn_husk".
- **Cart** (`game/items/cart.gd`): the lantern spot hangs at `LanternSocket` (Q-247 N1), the LightRig box lamp is hidden, N2 comment fixed.
- **Unreferenced models**: `prize_pumpkin.gd` uses `pumpkin_prize_<size>[_gnawed]` and places `pumpkin_patch` at the marker; `plot.gd` uses `crop_plot` (watered tint on the soil); `farm.gd` swaps the stand slab for `bldg_town_stand`.
