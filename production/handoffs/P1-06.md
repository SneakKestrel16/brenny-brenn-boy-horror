# P1-06: Proximity voice in game/voice/
Owner: Network & Voice  Date: 2026-10-07

## Done
- `game/voice/voice.gd`, autoload `Voice` (after `NoiseBus` in `project.godot`). Starts capture once on `Game.session_started`. Muted `Mic` bus with `AudioEffectCapture` (0.5 s); `VoiceBase` bus sends to `Voice` if that bus exists, else `Master`. TwoVoIP encoder: 24 kbps, complexity 8, RNNoise on, AGC off (doc 06 s8 "Encode").
- Open mic with VAD by default: opens at `NORMAL_DB - 15` dB (`NORMAL_DB` -20, fixed placeholder until the mic check), 15-frame hang, 5-frame pre-roll (100 ms). Push-to-talk: action `voice_push_to_talk` (V), on with `--ptt` or Settings `push_to_talk` once Gameplay adds the key (Q-042).
- Frames on channel 2 through `Net.send_bytes` (unreliable). Client to host `0x10` [flags, seq u16, volume byte, opus]; host relay `0x11` [slot, flags, seq, opus], volume dropped, radio bit cleared (no walkies in DD Phase 1), ghost bit set from the host's own `Game.is_ghost`. Type bytes moved off `0x01`/`0x02` because those are movement (Q-042).
- Host relay: sender keyed by transport id; slot is the speaker's index in `Game.players` order. Every 100 ms the host calls `NoiseBus.emit_voice(Game.players[peer].pos, loudest_byte, peer)` for each non-ghost speaker. Volume values are never logged or kept.
- `game/voice/voice_emitter.gd`, `VoiceEmitter` (`AudioStreamPlayer3D`), one per remote speaker, attached to `Players.player(peer)` at eye height. Own `AudioStreamOpus`, 60 ms jitter buffer, PLC only (D-012), decoder reset only at talk end. Inverse distance, unit 6 m, max 80 m (placeholders, doc 06 s8 "Playback").
- Logs (doc 06 s14): `voice_capture` once, `voice_sent` and per-speaker `voice_stats` every 10 s, `voice_stats` again when a player leaves. The `--voice-wav` file name is never logged.
- User args: `--voice-wav <path>` or `--voice-wav=<path>` (Windows path, e.g. `C:/...`; a Git Bash `/c/...` path is not readable and voice turns off with a warning), `--ptt`, `--voice-off`.
- `game/net/net.gd`: `send_bytes` skips peers not `STATE_CONNECTED`, uses unreliable (not ordered) on channel 2; throttle pinned (5000, 2, 0) on both ends (doc 06 s2, PP-02).
