# P5-44 Screen messages go off screen

## Root cause
Labels were added with fixed anchors and no `autowrap_mode`, so one long string made the label as wide as the text and it ran past the window edge. The project has no stretch mode, so the viewport equals the window in pixels.

## Fix (shared)
New `game/ui/ui_text.gd` (`UiText`): `fit(label, max_w, side)` turns on word autowrap, clamps the width to `min(max_w, viewport_w - 2*MARGIN)` (MARGIN 24) and re-applies on viewport `size_changed`. `slot_width()` does the same for the hotbar slots.

Used by: HUD top block, prompt (bottom anchored, grows upward), banner, hint, hotbar slots (`hud.gd`); `rejoin_toast.gd`; dev console toast (`game/debug/dev_console.gd`, one line, merge risk with P5-42/43); `imposter_input.gd`. Plain `autowrap_mode` added to `store_menu.gd`, `pause_menu.gd`, `lobby.gd` heading. `intro_card.gd` box width capped to viewport minus margins.

## Test
`tests/ui/test_screen_text.tscn` (windowed, needs a window): walks every visible Label/RichTextLabel at 1280x720 and 1920x1080 with a forced 400-char line and the longest hotbar strings, fails on any rect outside the viewport. Prints `SCREEN_TEXT PASS|FAIL`.
