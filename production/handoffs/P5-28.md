## Fix after QA
- `trait_report_pending` is no longer in `Save.build()` (dawn saves). It is set only on the season-start state in
  `Save.apply_pending`, next to `st.season_start = true`. A dawn save therefore loads with the flag false, so the trait
  line does not repeat; a season-start save still loads true (load run: flag true, 1 print at first dawn as before).
  Proof: two-instance run (port 54312) PASS; the season-1 dawn save has no key, the `_s2` season-start save has `true`.
  Not run: a full dawn in season 2 then load (the build path no longer writes the key, so inference).
- Lobby right panel now ends at offset_bottom -118 (above START, which starts at -110) and its contents sit in a
  ScrollContainer, so extra players or long text scroll instead of growing under the button. Screenshot
  `logs/p5_28/lobby4_1280x720.png` viewed: Imposter checkbox reachable by scroll, START clear. `--bots` do not appear in
  the lobby roster, so the 4-player roster height was not reproduced; the scroll covers it. 1920x1080 still could not be
  rendered (window clamped); anchors scale, inference. Lobby edits are layout only (no change near `_on_go`).
