Fix before pass:
- **F1, cart wheels have gaps.** The wheel rim is broken into separate blocks with gaps, so in game it reads as a
  sprocket or a broken wheel, not a wheel with an iron tyre. Source: `build_p4_40.py` `wheel()`. The 12 felloe boxes
  are 0.17 m long on a 0.49 m radius, but the chord is 2 x 0.49 x sin 15 deg = 0.254 m, so each gap is about 8 cm. The
  tyre boxes are 0.18 m long on a 0.535 m radius, but the chord is 0.277 m, so each gap is about 10 cm. Fix: set the
  lengths to the chord or a little more (about 0.26 and 0.285), or use one ring mesh. Then rebuild `prop_cart` and
  check it in game. Evidence: `logs/qa/p4_40/shots/cart_side.png` (in game, 3 m away). The handoff called this
  "slightly rough"; it reads as broken at pushing distance.
- **F2, animal sizes no longer match doc 07 s11.7, and the doc was not updated.** Built size against the doc row
  (w x l x h, m):

  | Animal | Built | Doc 07 s11.7 |
  |---|---|---|
  | cow | 0.59 x 2.30 x 1.30 | 0.8 x 2 x 1.5 |
  | pig | 0.47 x 1.40 x 0.66 | 0.6 x 1.2 x 0.8 |
  | chicken | 0.25 x 0.53 x 0.51 | 0.3 x 0.4 x 0.4 |

  The cow is 13% lower and 26% narrower than the doc. The old P4-16 cow matched the doc at 0.78 x 2.13 x 1.51.
  Fix: either scale the library meshes to the doc 07 dimensions, or keep the new sizes and update the s11.7 rows to
  "as built in P4-40", the way P4-19 did for the creatures. Choosing the second needs Director approval, because
  "real scale" sizes need a source. Smaller drifts to record in the same edit: `prop_cart` is 1.62 m wide (doc 1.5),
  and `tool_lantern` is 0.25 x 0.25 x 0.34 (doc 0.2 x 0.2 x 0.3).
