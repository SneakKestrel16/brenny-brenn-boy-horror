# P4-39 handoff (Gameplay)

Bug: `Save.apply_pending` runs `step_free_scrap` -> `refill_flare` -> `flare_reloaded` before `save_loaded`; the Dawn Report buffered it, so the next report showed a stale "Flare Gun" line.

Fix (root cause, one place): `DawnReport._on_logged` (`game/ui/dawn_report.gd`) clears `_events` on `save_loaded` and returns. Chosen over skipping the log in `refill_flare` because the store/death code stays untouched and the same guard covers any other event logged during apply. Inference: the resumed dawn's own report is built after the load (the save is written at step 6, before the report), so nothing legitimate is lost; a fresh load in a fresh process starts with an empty buffer anyway.

Test: `tests/gameplay/test_save.gd` now loads a save with a flare gun and 0 shots, asserts the gun reloaded and the buffer holds no `flare_reloaded`. Confirmed it FAILS with the fix disabled.
