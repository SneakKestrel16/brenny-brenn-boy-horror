# Handoffs

One file per finished task: `<task-id>.md`, written by the task's owner when it goes to review.

```markdown
# <task-id>: <title>
Owner: <role>  Date: YYYY-MM-DD

## Done
## Files changed
## What the next role needs to know
## Open issues
## QA review
Verdict: pass | fail. Reviewer notes. (Appended by QA; never by the task's owner.)
```
