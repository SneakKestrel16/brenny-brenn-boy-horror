## Node, mesh and material names for game code
- Crops: one `MeshInstance3D` named `Crop` under the root, origin at the plot soil surface (bulbs sink at most 0.03 m below it). Root node carries the file name. Swap the model by stage; stages 0..2 (turnip, pumpkin, moonflower) and 3 (turnip, pumpkin only) map to doc 02 growth, `_wilted`/`_rotten`/`_taint` to plot states `wilted`/`dead`. Moonflower has no stage3 and no rotten (doc 07 s11.5); `crop_moonflower_taint` is the dead-and-Tainting plot.
- Corn: one mesh node each, one surface: `Stalk` (lod0, lod1), `Card`, `Band`, `Cut`. All use the single material `mat_corn_stalk`, so each can feed a `MultiMesh` directly (`mesh = <node>.mesh`). Vertex colour (COLOR_0) holds a base-to-tip gold-green gradient `#8E8236` to `#B9A545` (doc 07 s2 corn); `corn.gdshader` ignores it and shades by height, so either works. Sway needs only `VERTEX.y`, origin is at the ground.
- Materials: `mat_flat_lit` (default, vertex colour), `mat_moonflower` (emissive `#7FE6D8`, used only on the moonflower stage2 petals and centre, doc 07 s2/s7; `crop_moonflower_stage1` bud and `_wilted` do not glow, matching "only moonflowers glow"), `mat_taint_surface` (oil black on `crop_moonflower_taint`, doc 07 s7; gameplay can override with the Taint shader), `mat_corn_stalk` (corn).
- `corn_stalk_lod0` has a cob and tassel (top at 2.4 m); `lod1` is a plain tapered stalk with two leaf quads. Materials are double-sided (no back-face culling).
- Import settings: every `.glb.import` uses `vcol_post_import.gd` (copied from the P5-12 tool imports; Godot then wrote `uid` and `path`).
