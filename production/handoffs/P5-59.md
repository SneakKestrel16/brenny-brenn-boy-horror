# P5-59 Textures and materials (Technical Artist)

Date 2026-10-10. Status: in review.

## What changed
- New `game/render/surface_detail.gdshader`: no textures. Two-octave value noise on the base colour, soft broad patches, per-instance tint from the object origin, roughness 0.88 +- noise, base x0.96 (slightly darker), detail fades 20-55 m. Static, no emission, no light change (doc 07 s4.4 rule kept).
- `assets/materials/mat_flat_lit.tres` is now a ShaderMaterial on that shader (vertex colour as albedo). CreatureLook loads it by name, so creatures follow.
- `assets/models/vcol_post_import.gd`: swaps every surface named `mat_flat_lit` in the glb models for that .tres at import (181 meshes: buildings, props, animals, farmer). The other `mat_*` (emissive, ghost, corn, moonflower, taint, overalls) are untouched.
- `game/render/world_look.gd` `_detail_pass`: ground, dirt paths and plain box props get the shader (world-space noise, same colour, one ShaderMaterial per colour). Skips emissive, transparent, unshaded, textured.

## Revert
