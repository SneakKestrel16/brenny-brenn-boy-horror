# P4-11: Phase 4 sabotage and difficulty
Owner: AI Programmer (Gameplay for settings)  Date: 2026-10-09

## Done
- **Dawn trample in Death step 5 (Q-086).** `Sabotage.dawn_trample()` is public, and Sabotage no longer hooks
  dawn itself. `Death.step_farm_damage` calls it (doc 02 s9 step 5). Placement follows doc 03 s10.1 and is
  done by `SabotageLogic.trample_pick`. Crops go first, weighted `1/(1+d/20)` by distance from the creature at
  dawn. A plot whose same crop was trampled at an earlier dawn gets half weight. Bare plots fill a shortfall
  and are churned with no coins lost. `farm_damage` sums `Plot.sell_value()` of the crops lost. The `trample`
  log gains `churned` and `full_wipe`.
- **Full wipe (doc 02 s14).** When every player is a ghost at step 5, the trample count is multiplied by
  `season.json` `full_wipe_damage_mult` (2). `Creature.wipe_traps` is set to `full_wipe_extra_traps` (2).
  `_plan_traps` adds that many next night, bear and pit in turn, then clears it.
- **Pumpkin gnaw (D-084, doc 03 s10).** A budgeted `pumpkin_gnaw` placed by day only marks a gnaw pending
  (`pumpkin_gnaw_spent`). Through the night Sabotage watches for a living player within `pumpkin.json`
  `guard_radius_m` (20 m). At dawn step 5 the gnaw lands with `PrizePumpkin.gnaw()` and leaves a
  `teeth_marks` disturbance with no fix. If someone came near, it logs `pumpkin_gnaw_blocked {reason: guarded}`.
  `gnaw()` itself refuses before night 3 and a second gnaw per night.
- **Scrap for fixes (D-085).** `bury`, `pull_seeds`, `repair_fence` (FixTarget) and `repair_generator` are
  refused with `no_scrap` when the team has none. Completing one calls `Store.take_scrap()`. `--autogen`
  grants free scrap. Bots buy one scrap (15 coins) when none is left, then do the fix. The scope is narrower
  than a literal reading of D-085 (plant is not charged), so Q-112 asks the Director.
- **Difficulty (doc 02 s16).** `Data.scaled()` applies `difficulty.json` after headcount scaling, rounded up.
  It maps `traps` to `trap_pct`, `bill` to `bill_pct` and `generator_tank` to `generator_tank_pct`.
  `Data.difficulty_scaled(v, kind)` is the shared hook. The generator tank reads it. Nightmare sets the
  lure's voice tell to `none` (doc 03). The trap race uses `ai_director.json` `nightmare_bend_m` (±5 m) and
  `nightmare_min_spare_s` (1 s).
- **Lobby group settings (doc 01 "Difficulty and group settings").** In the lobby the host presses F7 to
  cycle easy/normal/nightmare and F8 to toggle streamer-safe. The roster shows both to everyone.
  `Game.set_group_settings` sends RPC `Net.apply_group_settings(difficulty, streamer_safe)`, and joiners get
  it on admit. Each peer logs `group_settings`. QA flags: `--difficulty=<id>`, `--streamer-safe`.
  `match_started` logs both. The Dawn Report reads `Game.streamer_safe`.
- **D-075.** The ghost flag on a lure now applies by day too, not only at night.
- **D-081.** `Scares.jumpscare_id(body)` gives `cre_jumpscare_hit_<body minus body_>` when the wav exists,
  else `cre_jumpscare_hit`.
- **Q-089.** `_num["sanctuary_m"]` is filled before the Phase 1 table check, so the `--no-phase1` errors are gone.
