# P5-34 Barn signboard and intro scene

## What changed
- `game/world/barn_sign.gd` (`BarnSign`): a 6.2 x 3.9 m plank board with two `Label3D` columns on the barn's west wall
  (inside, centre -7.7, 2.4, -10), facing into the barn. Goal, day, dusk, night, Corrupted, traps, dawn. Text from doc 01
  (Core Loop, Taint, Night Traps, Nights, Season and Numbers); no new rules. Built on every peer from static text, nothing synced.
- `game/ui/intro_card.gd` (`IntroCard`, layer 108): full-screen text card, "FARMER'S DELIGHT", the situation, the goal.
  Local per peer. Shown when `Clock.day == 1` and no save is being loaded (`Save.pending` empty). Any key or click skips it
  (`Game.console_open` held while it shows, mouse freed then re-captured). Not shown headless or with `--no-intro`.
  Text only: no captions, no voice. Logs `intro_shown` / `intro_skipped`.
- `game/core/main.gd`: two hook lines (`BarnSign` after Generator, `IntroCard` before `WaitingCard`).
- `production/TASKS.md`: P5-34 row set to in review.

- Sign dims in a dark barn (plain material, no emission); readable by day and lit barn.

Failures:
1. **A client sees the intro on a loaded save.** `logs/qa34_B_*.txt`, port 54913: the host ran `load_season` on
   the `dawn_01` save and a client joined. At `start_match` the host showed no card, but the client logged
   `intro_shown` at day=1, phase=dawn. Cause: `game/ui/intro_card.gd:18`. `Save.pending` is set on the host only,
   and a dawn-1 save resumes at day 1. Every crash or quit before dawn 2 resumes this way.
   Fix: add `and Clock.phase == &"day"` to `wanted()`. A new season starts at `&"day"` (`Game._start_clock`). A
   loaded season-1 save resumes at `&"dawn"`, because season-start saves exist only for season 2 and later
   (`save.gd:275`). The client gets `apply_clock` before `apply_match_start` (the log shows phase=dawn at card
   time), so the check works on clients too. Then rerun the B scenario.
2. **The intro text contradicts doc 01 "Day deaths".** `game/ui/intro_card.gd:8` says "By day it only frightens
   you." Doc 01 lists two day kills (alone, Tainted and deep in the corn; losing the trap race), and the pillar
   says "frightens all day but only kills when someone took a risk".
   Fix: "By day it frightens you, and kills only those who take a risk."

Notes (no fix needed):
- `game/world/barn_sign.gd:7-8`: the board spans z -13.1 to -6.9 at y 0.45 to 4.35. That covers the inner half of
  barn windows `WindowGlow_1` (z -7) and `WindowGlow_2` (z -13). The window edges show at the board's sides in
  `sign34_far.png`. This is cosmetic only. A board 4.9 m wide would clear both windows, but it needs a smaller
  `PIXEL_SIZE` (inference: about 0.0029 would keep the text fitting).
- If a client rejoins a running season during day 1, it sees the intro again. This is a minor edge case. The fix
  above does not cover it.
- The intro says "seven days" and leaves out the first payment after night 3. This is a simplification, not a
  wrong rule.
