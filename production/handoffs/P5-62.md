## Fixes made (small, clearly correct; uncommitted)

1. `tools/sim/test_sim.py` (Game Designer's path, fixed under the task brief): the roles count went from 10
   to 12 when P5-52 (Crowkeeper) and P5-53 (Horror) added rows to `data/roles.json`. The data is right; the
   assertion was stale. Now 12, comment names both tasks.
2. `tests/gameplay/test_emotes.gd` (Gameplay's test): the `data.gd` node it creates was never freed, so exit
   printed `ERROR: 1 resources still in use at exit` and 9 leaked instances. Added `data.free()` after use.
3. `tests/qa/fake_peer.gd` (QA): every client printed `ERROR: Condition "!peers.has(p_id)"` from
   `net.gd _pin_throttle` because the fixture left `server_relay` on, so the Net autoload got `peer_connected` for
   clients it has no ENet peer to. Set `server_relay = false`, the game's star topology (`net.gd _use`). The game
   itself is unaffected (it always sets relay off).
